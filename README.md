# Zahleninsel 🐾🔢

Ein Lernspiel für Kinder ab 3 Jahren: Zahlen bis 10, Mengen, erste Buchstaben, Farben, Formen und Tiere – zusammen mit einem eigenen Hund auf einer kleinen Insel.

- Alles wird vorgelesen, das Kind muss nur antippen.
- Fehler sind nicht schlimm: Die richtige Antwort wackelt, und es gibt immer ein Lob.
- In jeder Runde entsteht ein Bild (Rakete, Bagger, Dino …), am Ende gibt es ein Feuerwerk.
- 10 Minuten Spielzeit am Tag, dann geht der Hund schlafen. Im Elternbereich lässt sich das ändern.
- Komplett offline: keine Werbung, keine Anmeldung, keine Daten werden verschickt.

## So installierst du das Spiel (Android)

1. Den Link oben **am Handy oder Tablet** antippen. Die Datei `Zahleninsel.apk` wird heruntergeladen.
2. Die Datei öffnen (Benachrichtigung antippen oder im Ordner „Downloads“).
3. Beim ersten Mal fragt Android, ob Apps aus dieser Quelle installiert werden dürfen: **„Zulassen“** einschalten und zurückgehen.
4. **„Installieren“** antippen. Fertig – die Zahleninsel liegt jetzt bei den Apps.
5. Beim ersten Start fragt das Spiel nach dem Namen des Kindes, dann sucht sich das Kind einen Hund aus.

**Neue Version?** Am einfachsten in der App: Elternbereich → **„Nach Update suchen“** (dann bleibt keine Datei im Download-Ordner liegen). Oder wieder über die Seite herunterladen und **„Aktualisieren“** antippen. Der Spielstand bleibt erhalten. Bitte die App vorher **nicht** deinstallieren, sonst ist der Spielstand weg.

Google Play Protect zeigt eventuell einen Hinweis, weil die App nicht aus dem Play Store kommt. Dann „Trotzdem installieren“ wählen.

## Für Eltern

- **Elternbereich**: Zahnrad oben rechts **1,5 Sekunden gedrückt halten**, PIN **1234** (lässt sich ändern).
- Dort: was das Kind schon kann, Spielzeit pro Tag, Zeit heute verlängern, Aufgaben an- und ausschalten, Name ändern, Spielstand sichern.
- Funktioniert auf Android-Handys und -Tablets. Für iPhone/iPad gibt es keine Version.
